# Personal Expense Tracker

A simple command-line personal expense tracker built with Python to help you log and monitor your daily spending.

## Features
* Log daily expenses with categories and descriptions
* View expense summaries and totals
* Lightweight and interactive CLI interface

## Requirements
* Python 3.x

## How to Run
1. **Clone the repository:**
   ```bash
git clone https://github.com/Joshna-Pandiripilli/personal-expense-tracker.git
```
2. cd personal-expense-tracker
3. python expense_tracker.py
